# O-Troco-Kotlin
Sistema bancário desenvolvido em Kotlin, com funções de saldo, extrato, saque, depósito, transferência e validação de senha.

O sistema permite:

Cadastro do nome do usuário;
Consulta de saldo;
Visualização de extrato;
Saques com validação de saldo;
Depósitos com validação de valores;
Transferências entre contas;
Validação de senha para operações bancárias;
Validação de entradas do usuário;
Opção para encerrar o sistema.
